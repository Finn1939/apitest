# Character notes

`personality.txt` defines Capri's current voice: sharp, mischievous, observant, and conversational, with a cyberpunk edge used sparingly. It also describes how she should handle server actions, uncertainty, memory, and media context.

This is an original fan interpretation, not a claim of exact canon reproduction. Voice quality depends on the selected model and the actual conversation. If `PERSONALITY_PATH` points to a custom file, updating `personality.txt` will not replace that file.
